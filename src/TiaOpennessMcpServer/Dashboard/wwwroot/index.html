Connection help & diagnostics

Connect an existing TIA window from its workspace. Selecting a workspace changes only this view. Each call targets that workspace’s process. Read and write operations call the published MCP tools. Writes change the connected project in memory; save it in TIA when ready.

Server history lasts until restart. Run captures are retained in server memory. Object selections are cleared when the project or connection changes.

Background checks run while a visible dashboard has an open event stream. Each operation also checks its project context.
