# Inert pre-transition reference

`legacy-v1/` preserves the 72 tracked source, test, documentation, editor-task and lifecycle-helper files selected from commit `8ebc151` before the 2026-09-21 source transition. No build outputs, local lifecycle token/state or TIA project files were copied. Source/test files include the then-current connection prototype so the complete baseline remains understandable.

This is comparison material only. Do not build/run its server, tests, mutating editor tasks or lifecycle helper as part of active work. Instructions and capability claims inside this snapshot are historical. The active project and harness have no dependency on it.

The active guarded foundation deliberately retains the connection/discovery implementation and generic STA/WinForms host. V1 services, models, parsing/export/write helpers and engineering dispatch have been retired from active source. Eight disabled descriptors remain in the active MCP host only as an explicit publication hold, never as a runtime fallback.
